# PR-Tracking
Implementing QB tracking capstone into the GitHub

WR_ESP32_Code.cpp is the code for each of the receivers and the QB_ESP32_Code.cpp is the code for the quarterback. If you are using a new esp32, you will need to update the robots mac address in the code for the system to properly communicate. Additionally, if you change the DWM1001 board on the receivers, you will need to update the 0xDECA... ID, which you can find in the decawave DWM1001 development app.
